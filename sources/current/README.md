# Foundations of Algebraic Geometry — corrected English edition

Eight Bourbaki exposés, their errata and the 1962 comments, in English. The texts cover formal geometry, representable functors, descent, Hilbert and Picard schemes, and group schemes.

[en/main.tex](en/main.tex). Compile with LuaLaTeX from the `en` directory. The shared preamble is `tex/base.tex`.
